Introduction
============

This document describes the signature of the ADGlib library. 
The signature is a collection of predicates and functions symbols for the manipulation of geometric objects. 
The objective is to facilitate the communication between different tools manipulating geometric statements.

The core predicate symbols are supported by the ADGToolbox.

Naming conventions
__________________

Camlcase is used for the names of the predicate and function symbols. 
All predicate and function symbols begin with a lowercase letter, this is required for compability with TPTP.

We chose to use rather long names for the predicate and function symbols, to make them self-explanatory.

Latex style file
________________

A LaTeX style file is provided, it defines some infix notations for some predicates. 
The name follows the names of the ADGsignature when possible.
The style file is designed to be used with latex or pdflatex or xelatex.
