This directory contains the source for the specification of the ADGLib signature. 
We use [Sphinx](https://www.sphinx-doc.org/en/master/) tool. 

To compile use:
```make html``` or ```make latexpdf```

You need to have the style file ```adgsignature.sty``` in a path accessible to your latex installation, for example, under MacOSX copy the style file to:
```~/Library/texmf/tex/latex/```
